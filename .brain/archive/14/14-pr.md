M20 step 7: native tray, service panel, close to tray, single instance

Summary
- Closing the native window hides it; Zenv and its services keep running in the notification area.
- Tray icon: left click opens the service panel (same layout as the React TrayPanel: running/stopped groups with switches,
  newest error, Start apps / Stop all, Open Zenv / Quit), right click shows Open / Quit, double click opens Zenv, the tooltip
  names the running services.
- A second launch on the same Zenv home signals the running one to show its window and exits.
- The window has the Zenv icon.
- Core platform: `single_instance`, `work_area`, `find_window` (Windows + fallback).

Evidence
- zenv-core platform tests 10 passed; zenv-native `tray` tests 12 passed; device run on C:\zenv-dev (see 14-dev.md).

Risks
- eframe 0.37 cannot open immediate viewports while the root is hidden (G-016); the panel is a deferred viewport.
- Quit with live services was proven by code path, not on the device.
