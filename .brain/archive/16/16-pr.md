M20 step 8b: native Studio terminals

## Summary
- The native Studio window gets the terminal panel of the React UI: tabs of Claude Code / Codex / PowerShell running in the app's folder,
  `+` menu from `Core::studio_agents`, LED per tab, close ends the program, Enter restarts after exit, Ctrl+` and the PanelRight
  button, the splitter (share persisted), the "Empty editor" close, and closing the window ends its programs.
- `studio/terminal/`: own terminal widget on `alacritty_terminal` 0.26 (grid + vte parser; the PTY stays portable-pty in core):
  xterm key encoding, bracketed paste, SGR/X10 mouse reports, selection + Ctrl+C copy, scrollback, focus reports, the React theme
  colours with 256/truecolor, answers to the program's queries from the reader thread (`Outbox`), OSC 52 off.
- One galley per ASCII stretch with colour sections; Segoe UI Symbol (Windows fonts folder) as monospace fallback for Claude Code's symbols.
- Editor shortcuts (Ctrl+S/F, Shift+Alt+F) stay out of a focused terminal.

- Real window (debug build, dev home): Claude Code with colours and keys, vim, truecolor, maximize resize, two-line paste saved by vim,
  no orphan processes after closing the window. Details in 16-dev.md.
